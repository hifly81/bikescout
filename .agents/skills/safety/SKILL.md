# Skill: BikeScout Technical & Safety Operations

This skill defines the technical resources, safety protocols, and mechanical baselines for the BikeScout ecosystem. The agent must use these guidelines to validate rider readiness and equipment setup.

## 1. Pre-Ride Safety Protocols
Every mission must start with these mandatory verification steps.

### Base Commands (All Bikes)
- **Helmet**: Verify structural integrity and buckle functionality.
- **GPS/Navigation**: Check battery levels and ensure offline maps are synced.
- **M-Check**: Inspect hubs, bottom bracket, and headset for mechanical play.

### Specialized Discipline Protocols
| Bike Type | Critical Checks |
| :--- | :--- |
| **E-Bike** | Battery SoC (>80%), Power mode test, Speed sensor magnet alignment. |
| **MTB** | Shock/Fork sag & pressure, Dropper post operation, Knee/Elbow pads integrity. |
| **Gravel** | Tubeless sealant levels, Frame bag clearance, Flare bar alignment. |
| **Road** | Brake pad wear (Rim/Disc), High-pressure tire casing, Rear light battery. |
